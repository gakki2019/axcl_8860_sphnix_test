常见问题
========

本页整理文档浏览、环境准备和首次开发过程中最常见的问题。

如何在本地构建文档？
----------------------

安装 `docs/requirements.txt` 中列出的依赖，然后在 `docs` 目录执行 HTML 构建命令。

为什么中英文页面要分开导航？
------------------------------

站点需要保证任意页面只渲染当前语言的侧边栏树，因此中英文内容采用平行目录，并避免在同一导航树中混排。

如果我只关心 C/C++ API，应该从哪里进入？
------------------------------------------

从当前语言首页进入开发文档，再从 C/C++ 节点进入接口树即可。
