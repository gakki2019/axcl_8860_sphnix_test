# 快速开始

## 目标

本页提供一条最短上手路径，帮助新读者从代码仓准备进入到文档站点构建成功，再过渡到开发相关内容。

## 首次流程

1. 打开仓库根目录。
2. 安装文档依赖。
3. 在 `docs` 目录执行 HTML 构建。
4. 用浏览器打开 `docs/build/html/index.html`。
5. 确认当前语言首页和导航树渲染符合预期。

## 重点检查项

- 首页可以正常访问。
- Markdown 页面可正确渲染。
- 当前语言的导航树独立显示，不与另一种语言混排。
- 开发文档中的 C/C++ API 树可从侧边栏进入。

## 下一步

首次流程确认后，可继续进入开发文档查看架构说明和 API 参考内容。
