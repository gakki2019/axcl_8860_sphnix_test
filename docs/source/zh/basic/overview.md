# 概览

## 页面目的

本页用于介绍 AXCL SDK 文档集的整体结构，帮助读者在阅读安装指南、快速开始和开发文档之前先建立全局认识。

## 适用范围

- 初次接触 AXCL SDK 的读者。
- 需要快速判断文档入口和阅读路径的开发者。
- 需要了解文档边界和后续阅读顺序的维护人员。

## 文档结构

当前文档按以下三类组织：

- 基础文档：说明概览、安装和快速开始。
- 开发文档：说明架构、C/C++ 与 Python 相关内容。
- FAQ：整理常见问题和初始排障入口。

## 建议阅读顺序

1. 先阅读 [安装指南](install.md) 完成环境准备。
2. 再阅读 [快速开始](quick_start.md) 完成首次流程验证。
3. 完成入门后进入开发文档查看架构与接口资料。
