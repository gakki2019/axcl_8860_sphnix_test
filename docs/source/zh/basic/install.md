# 安装指南

## 页面目的

本页用于说明构建 AXCL SDK 文档站点以及准备 SDK 开发环境时建议完成的前置步骤。

## 推荐准备项

- 确认用于构建文档的操作系统和 Python 环境。
- 准备 SDK 所需的编译工具链和运行时依赖。
- 确认仓库已切换到目标分支或发布标签。

## 文档构建准备

文档站点基于 Sphinx 构建，同时支持 reStructuredText 与 Markdown 页面。

典型准备流程包括：

1. 安装 `docs/requirements.txt` 中列出的 Python 依赖。
2. 在 `docs` 目录执行 HTML 构建。
3. 打开 `docs/build/html` 下的输出结果进行本地检查。

## SDK 环境准备

在运行 SDK 示例或接入 AXCL 能力之前，建议确认以下项目：

- 设备访问权限是否就绪。
- 所需共享库和运行时包是否已安装。
- 首次验证流程所需的模型文件、样例数据或测试素材是否已准备。

## 下一步

环境准备完成后，继续阅读 [快速开始](quick_start.md) 完成首次上手流程。
