# 系统架构

## 总览

AXCL SDK 可以理解为一个分层系统，对外提供应用接口，对内负责运行时服务、设备资源和执行调度。

## 核心层次

- 应用层：负责把 SDK 接口集成到业务程序、工具链或验证流程中。
- 运行时层：负责上下文管理、设备选择、流提交、内存搬运和引擎执行。
- 资源层：负责设备资源、缓冲区和同步原语。

## 典型执行流程

1. 初始化运行时。
2. 选择设备并创建所需上下文。
3. 分配或绑定内存资源。
4. 通过流或引擎接口提交工作负载。
5. 同步、收集输出并释放资源。
