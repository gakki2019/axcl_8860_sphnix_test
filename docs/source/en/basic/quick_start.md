# Quick Start

## Goal

This page provides a concise first-use path so a new reader can move from repository checkout to a successful documentation build and then to the first development-oriented section.

## First Workflow

1. Open the repository root.
2. Install the documentation dependencies.
3. Build the HTML site from the `docs` directory.
4. Open `docs/build/html/index.html` in a browser.
5. Verify that the current language entry and navigation tree render as expected.

## What to Check

- The home page opens successfully.
- Markdown pages render correctly.
- The current language navigation is visible without mixing both language trees.
- The C/C++ API section is reachable from the development tree.

## Next Step

After completing the first workflow, continue with the development section to review architecture and API references.
