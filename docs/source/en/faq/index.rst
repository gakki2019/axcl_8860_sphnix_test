FAQ
===

This page collects common questions raised during documentation browsing, environment setup, and initial development.

How do I build the documentation locally?
-----------------------------------------

Install the packages listed in `docs/requirements.txt`, then run the HTML build from the `docs` directory.

Why are English and Chinese pages separated?
--------------------------------------------

The site keeps the English and Chinese trees parallel so each page can render a language-specific navigation structure.

Where should I start if I only need the C/C++ APIs?
----------------------------------------------------

Open the development section and enter the C/C++ API tree from the language-specific home page.
